Executive Briefing for Technical Recruiters & Engineering Leads

State-of-the-art SWE agents (SWE-agent, Devin) cost millions in cloud GPU subscriptions and require 128k context windows. BAGR proves that an open sub-3B parameter model running on an ordinary 8 GB laptop CPU can achieve an 80.0% Pass@1 rate across multi-file repository bugs. By substituting raw parameter scale with deterministic Abstract Syntax Tree graphs, budget knapsack packing, and evidence sandboxing, BAGR cuts inference cost to $0 while guaranteeing data privacy.

The Four Cooperating Mechanisms

A modular, mathematically grounded architecture engineered specifically for hardware-constrained autonomous repair.

Mechanism A
Repository Graph (RDG)
Parses multi-file ASTs into a typed directed multigraph capturing classes, functions, calls, imports, and test linkages via NetworkX in < 0.25s.
Mechanism B
Budget Context Selector
Propagates Personalized PageRank (α=0.85) over AST symbols and applies greedy knapsack packing to enforce hard context caps (≤ 2,048 tokens).
Mechanism C
Evidence-Gated Repair
Enforces a strict 3-stage validation contract: Block Applicability → AST Syntax Parsing → Isolated Pytest Subprocess with distilled tracebacks.
Mechanism D
Adaptive Controller
Tracks memory telemetry and CPU latency in real time, contracting graph search depth (2-hop → 1-hop) if system RAM allocation exceeds safety ceilings.
